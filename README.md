# HYROX Bangkok Guide

Travel • Race • Recover

## Local Preview
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub Pages
1. Upload this project to a GitHub repository.
2. Run:
```bash
npm install
npm run build
```
3. In GitHub Pages, set source to GitHub Actions or deploy `dist`.
4. Or use:
```bash
npm run deploy
```

## iPhone Install
Open the GitHub Pages URL in Safari → Share → Add to Home Screen.
